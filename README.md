# Stat Fick

- `engine/`: Statventure, a C#/Vulkan engine on BRUTAL, and the port of Stat Fick onto it. Start
  with `engine/Docs/Engine-Plan.md`.
- `old-game/`: the original Stat Fick (JavaScript, Electron), which the port is checked against.

Build and test the engine: `engine/Tools/Scripts/test.sh` on Linux,
`engine\Tools\Scripts\test.ps1` on Windows (run `setup.ps1` once first). See `CLAUDE.md` for the
machines this is worked on.
