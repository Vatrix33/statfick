# The licence texts the packages ship and what each covers (Q10; Docs/Packaging.md, "How it works", step 3).
#
# text <shipped path> <source>
#   A text kept in this folder, shipped in every package at that path (NOTICE.txt beside the program, licenses/<name>),
#   and where it came from: nuget:<package>/<path in the package> (at the version the publish resolved; * matches any
#   part of a package name, {rid} is the publish's runtime), repo:<path from the repo's root>, or fixed:<where it was
#   taken from> for a text that is in no package or file of the repo (kept as committed, not compared). The publish
#   checks each text against every source named for it (the same text, line ends aside) and refuses a text in this
#   folder with no line here.
# cover <pattern> <text>... | -
#   The texts that cover a file of a package: a pattern on paths in the program's folder ({program} is the program's
#   executable), or bundle:<pattern> on the files inside the single-file program. The first line that matches counts;
#   "-" is a file that needs no text (the engine's and the game's own files, the texts themselves, the Visual C++
#   runtime, which Visual Studio's licence lets its users ship). check-packages.sh fails on a file no line covers and on
#   a covering text missing from the package.
