# Task 12, Spell Rework: the drafts

The user's task is `../12_Spell_Rework.txt`. It is designed here for the port and not built in the old game (SP1); the
drafts live in this folder from the start (SP21). The decisions are SP1 onward in `../../Engine-Plan.md`, "Decisions
for task 12, Spell Rework".

The review's order (SP2, SP15):
1. `Spell-Augmentation.md`: the spells' new system and the power curve every spell follows. **Approved (SP27).** The
   Augmentation menu's look was given with the notes (SP25).
2. A sample of four reworked spells (not written yet).
3. One batch per element: every spell players can learn, reworked (the seven boss and enemy-only spells are left out,
   SP4).
4. The new spells, element by element: two per element in each of Tiers 1–5, one in each of Tiers 6–9, Basic
   included (168, SP3); at least four new summons, one each for Nature and Death and two for the elements with the
   fewest summons.
5. The Spellweaver (built around Spell Augmentation, SP9) and the Ritual Caster, added to task 10's drafts
   (`../10_Class_Rework/`).
